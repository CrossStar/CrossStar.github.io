仍然从引入 harmful/harmless 的定义出发

定义

  • 描述：指自然语言中的任意文本片段，其形式可以是一个词语、一个句子，或一篇完整的篇章。它作为信息表达的基本单元，用于承载语义内容并参与概念、定义或状态的建构过程。
  • 定义：“定义”本身亦可视为一种“描述”，但其特殊之处在于具有判别功能。形式上，定义可视为一个二分类器，其作用是将所有可能的描述集合（包括该定义自身）划分为“符合定义”与“不符合定义”两类。
    • 定义的一般表达形式为：

在条件 C 下，满足特征 F 的描述被称为具有属性 P。\text{在条件 C 下，满足特征 F 的描述被称为具有属性 P。} 在条件 C 下，满足特征 F 的描述被称为具有属性 P。

其中，C 被称为条件，用于限定定义的适用范围；F 被称为特征，用于刻画定义的本体判别性特征；P 被称为属性，用于表达定义赋予对象的概念名称

  • 状态：标准形式下的定义中，在上述定义的标准形式中，条件 C 与特征 F 统称为状态；对于任意一个描述，我们可以基于该定义对其进行状态判断：即判定该描述是否符合某一状态或不符合某一状态。

后续推理

  1. 人类在进行判定某一个句子是 harmful 还是 harmless 的过程中，往往是从自己的先验知识中分析什么样的描述是满足 harmful 的定义的，然后将现有的句子和 harmful 的定义进行比对
  2. 于是我们可以构建 harmful 的总定义：D=D1⊕D2⊕…⊕DnD = D_1 \oplus D_2 \oplus \ldots \oplus D_nD=D1​⊕D2​⊕…⊕Dn​，其中 DiD_iDi​ 是每一个有关 harmful 的 “子定义”，只要 DiD_iDi​ 中有任意一个能够把现有的描述划分为 harmful，那么就可以判定这个句子是 harmful 的
  3. 那么现在的问题就转换成了如下的形式：
    1. 收集有关 harmful 的系列定义语料，并将其转换为标准形式（比如可以列出一个表格，每一行代表一个定义，列分别代表条件，特征和属性）
    2. 对于现有的语句，逐定义判断其是否可被划分为 harmful。这意味着对语句逐个判断每个定义的条件 C 和特征 F 是否成立

由于条件 C 和特征 F 均可被视为状态，那么问题就被简化为：

对于一个描述 L，以及一个状态 S，如何快速判断 L 是否满足 S？\boxed{\text{对于一个描述 L，以及一个状态 S，如何快速判断 L 是否满足 S？}} 对于一个描述 L，以及一个状态 S，如何快速判断 L 是否满足 S？​

那么这个问题有如下几种解决方式：

  1. 把描述 L 和状态 S 分别向量化为 h(xL)\mathbf{h}(x_L)h(xL​) 和 h(xS)\mathbf{h}(x_S)h(xS​)，然后通过计算它们的相似度（比如余弦相似度，欧式距离）来判断是否满足状态 S。

  2. 微调一个判别模型，输入为描述 L 和状态 S，输出为二分类结果，表示 L 是否满足 S。

  3. 根据 10.20 的想法，状态 S 实际上是分布在语义空间的一个流形上的，那么只需要找到这个流形，然后看是否满足相应的条件就行了，但这样显然太复杂

优点：

  1. 该方法的容错率比较高，比如 DiD_iDi​ 中有任意一个能够把现有的描述划分为 harmful，那么就可以判定这个句子是 harmful 的，存在纠错机制
  2. 该方法不依赖训练中的标注数据，能够在无监督或少量标注的情况下进行有效判定
  3. 该方法可以随时修改定义，以适应随着新数据或新知识的出现而变化的语义边界

进一步讨论

如果使用这个方法，问题的主要的难点就转化为了如何构建 harmful 的定义集从而能够做到不重不漏，这实际上又可以从已知的数据出发。对于现有已经标注过的数据，如果是 harmful 的话就可以先生成对应的一个可能的定义，然后循环判断后面的数据是否满足先前生成的定义，如果不满足则再次生成
